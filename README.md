# Church CTV community

Organization profile, default community files and shared policies. Product code
lives in the four platform repositories; this repository holds no product code,
so its own `LICENSE` is the same license offered for the organization-wide
community files.

Questions about the software: open an issue in the relevant product repository —
anyone may. Permissions, commercial licensing, sales and support:
`dominick253@gmail.com`. Security reports: the Report a vulnerability form on a
product repository's Security tab, never a public issue. See `SUPPORT.md`,
`SECURITY.md`, `CONTRIBUTING.md` and `LICENSE`.

| File | What it settles |
| --- | --- |
| `LICENSE` | Church CTV Community Source License 1.0, the operative grant |
| `CONTRIBUTOR-AGREEMENT.md` | what a contributor keeps and what they grant |
| `LICENSING-STATUS.md` | what the license claims and does not |
| `SUPPORT.md` | issues for questions, email for money and permissions |
| `SECURITY.md` | the private reporting channel and its limits |
| `CONTRIBUTING.md` | how a change is proposed, tested and merged |
| `RELEASE-STATUS.md` | what "public source" does not mean |
| `ISSUE_TEMPLATE/` | the default issue forms the product repositories inherit |
| `.github/ISSUE_TEMPLATE/` | the same three forms, for this repository itself |

Public source is not a supported release, a store approval, a device
certification or a production migration, and publishing this source did not move
production.
